# JSON 树图工具设计

## 需求描述

新增工具箱功能：JSON 树图工具。参考 https://treease.com/editor ，核心特色是把 JSON 数据渲染为可交互的**横向节点树图**，并提供语法高亮编辑器、格式化/压缩/校验、搜索高亮与编辑器↔树图双向联动定位。

**已确认的范围决策：**

| 决策点 | 结论 |
|--------|------|
| 展示形式 | 全屏标签页（`chrome.tabs.create` 打开扩展自带页面） |
| 功能范围 | 编辑器基础能力 + JSON 转树图（核心）+ 搜索与双向联动 |
| 技术路线 | 手写 SVG 树图 + vendored CodeMirror 5 编辑器 |
| 树图布局 | 横向左右展开（根在左，子节点向右逐层展开） |
| 数据导入 | 仅粘贴/手动输入 |
| 集成方式 | JsonTool 继承 BaseTool，execute() 只负责打开全屏页 |

**本期不做：** PNG 导出、本地文件导入/拖拽、嵌套 JSON 字符串解析、暗色主题、URL 抓取、对比模式。

## 总体架构

```
popup 工具列表
  └── [🌳 JSON 树图工具] 卡片 → JsonTool extends BaseTool
        └── execute() → chrome.tabs.create 打开全屏页
                        （已打开则复用并聚焦该标签页）

tools/json-tool/                 # 独立 ES6 模块入口，不依赖 popup
  ├── index.html                 # 页面骨架：工具栏 + 左右双栏
  ├── tool.css                   # 样式
  ├── main.js                    # 入口：组装编辑器/树图/搜索/联动
  ├── editor.js                  # CodeMirror 封装：高亮、格式化、压缩、光标事件
  ├── json-parser.js             # 手写递归下降解析器：AST + 每节点源码区间（纯函数）
  ├── tree-model.js              # AST → 树节点模型，path ↔ 源码区间映射（纯函数）
  ├── tree-layout.js             # 横向整洁树布局算法（纯函数）
  ├── tree-graph.js              # SVG 渲染 + 缩放/拖拽 + 折叠 + 高亮
  └── search.js                  # 搜索状态：匹配过滤、循环跳转

lib/codemirror/                  # vendored 第三方库
  ├── codemirror.min.js          # 核心
  ├── codemirror.css             # 编辑器样式
  ├── mode/javascript.min.js     # JSON 语法模式
  └── addon/edit/matchbrackets.min.js
```

### 关键设计决策

1. **手写 JSON 解析器（json-parser.js）**：双向联动需要「每个 JSON 节点 ↔ 源码区间」的映射，`JSON.parse` 不提供位置信息。手写递归下降解析器（约 200 行，纯函数）同时解决：
   - 每个节点的源码 `[start, end)` 区间（联动与搜索的基础）
   - 校验错误的行列号定位
   - 嵌套深度上限保护（500 层，防栈溢出）

2. **核心逻辑与 DOM 解耦**：parser / tree-model / tree-layout 均为纯函数模块，不接触 DOM；DOM 相关逻辑隔离在 editor.js / tree-graph.js。项目无测试基建，纯函数设计为将来补测试留路。

3. **集成方式**：JsonTool 继承 BaseTool，保持与现有工具一致的注册模式（constants.js 加 `TOOL_TYPES.JSON_TREE` + popup.js 注册）。execute() 打开全屏页，全屏页自身是独立 ES6 模块入口，与 popup 完全解耦。**manifest.json 无需任何改动**。

## 数据流

```
编辑器内容变更（300ms 防抖）
  → json-parser 解析
      成功 → tree-model 建树（path 如 $.a.b[0]、源码区间、值摘要）
           → tree-layout 计算坐标（深度→x，叶槽→y）
           → tree-graph 渲染 SVG（按 path 保留折叠状态）
      失败 → 工具栏红条「第N行第M列：错误信息」，可点击跳转出错行
           → 树图保持上次有效快照
```

### 双向联动

- **树图 → 编辑器**：点击树节点 → 编辑器滚动到该节点源码区间并高亮背景（离散点击，无需防抖）
- **编辑器 → 树图**：光标移动（防抖）→ 取「最深包含光标 offset 的节点」→ 树图对应节点高亮描边

### 搜索

- 输入防抖 → 匹配 key 与标量值（不区分大小写，包含匹配）
- 树图：匹配节点橙色高亮，非匹配节点淡化
- 编辑器：`markText` 标记所有匹配文本
- Enter / Shift+Enter 在匹配列表中循环跳转：自动展开被折叠的祖先节点并居中滚动

## 交互与视觉

### 页面布局

```
┌──────────────────────────────────────────────────────────────┐
│ [示例] [清空] [格式化] [压缩] [复制]   [🔍 搜索框]  ✓ 有效JSON │
├────────────────────────┬─────────────────────────────────────┤
│                        │                                     │
│   CodeMirror 编辑器     │          SVG 树图画布               │

└────────────────────────┴─────────────────────────────────────┘
```

### 树图节点卡片

- 内容：类型色点 + key 名 + 值摘要（长文本截断）+ 子节点数徽标
- 折叠态：显示 `{…}` / `[…]` + 子节点数量
- 折叠规则：点击节点上的 ± 切换；单层子节点 > 50 时该层默认折叠

### 画布操作

- 滚轮缩放（以光标位置为中心）
- 拖拽平移
- 工具按钮：放大 / 缩小 / 适应画布 / 重置

### 主题

- 浅色主题，主色沿用工具箱现有紫渐变 `#667eea → #764ba2`
- 类型色：object 紫 / array 蓝 / string 绿 / number 橙 / boolean 青 / null 灰

### 空状态

初始载入一份示例 JSON，打开即见树图效果（参考站做法）。

## 错误处理与边界情况

1. **无效 JSON**：不阻塞编辑。树图保持上次有效快照；错误条显示行列号，点击跳转出错行。
2. **嵌套过深**：解析器深度上限 500 层，超出报「嵌套超过 500 层」错误，防栈溢出。
3. **超大 JSON**（万级节点）：直接渲染，不做事先优化。布局为纯函数，性能不足时后续按需优化（虚拟化不在本期范围）。
4. **标签页复用**：execute() 先 `chrome.tabs.query` 查找已打开的本工具页，找到则 `chrome.tabs.update` 激活，避免开多个重复标签页。
5. **编辑器与树图状态同步竞态**：解析-渲染管线由单一入口（防抖后的 handleInput）驱动，折叠状态按节点 path 存储在 tree-graph 内部，重渲染时恢复，避免闪烁。

## 验收标准

- [ ] popup 出现「JSON 树图工具」卡片，点击打开全屏标签页；再次点击复用并聚焦已开标签页
- [ ] 粘贴合法 JSON 后树图实时更新；粘贴非法 JSON 显示行列号错误条且可点击跳转
- [ ] 格式化（2空格缩进）与压缩往返不丢数据
- [ ] 树图：节点卡片按类型着色；折叠/展开正常；单层子节点 >50 默认折叠
- [ ] 画布：滚轮缩放（以光标为中心）、拖拽平移、四个工具按钮生效
- [ ] 搜索：匹配节点橙色高亮、其余淡化；Enter/Shift+Enter 循环跳转并自动展开折叠祖先
- [ ] 双向联动：点树节点 → 编辑器滚动并高亮对应源码；点编辑器位置 → 树节点高亮描边
- [ ] 复制按钮复制当前编辑器内容
- [ ] 深嵌套（50层）、大数组（1000+ 元素）页面不崩溃
- [ ] 现有 Cookie / XPath 工具不受影响

## 风险评估

- **风险等级**：低
- 纯增量变更，只新增文件 + 两处注册改动，不触碰现有工具逻辑
- manifest 无改动，无新权限
- 主要不确定性在树图布局算法的手写实现，但算法（整洁树布局）是成熟方案，且为纯函数便于隔离调试
